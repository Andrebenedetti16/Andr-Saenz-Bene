# Andr-Saenz-Bene
⛽ Gasolina - Análise de Preços de Venda (Julho/2021)
Este projeto tem como objetivo analisar os preços de venda da gasolina no Brasil durante o mês de julho de 2021, utilizando dados públicos para extrair insights econômicos e regionais sobre o comportamento do combustível no período.

📊 Contexto
Em 2021, o preço da gasolina apresentou variações significativas devido a fatores como:

Alta do dólar

Reajustes da Petrobras

Aumento da demanda no pós-pandemia

Impactos logísticos e tributários

Com base nesses fatores, este projeto visa investigar como os preços se comportaram nas diferentes regiões do país e identificar tendências, outliers e possíveis padrões de mercado.

📁 Fontes de Dados
📌 ANP - Agência Nacional do Petróleo
Dados coletados através de relatórios públicos semanais da ANP referentes a julho de 2021.

🛠️ Ferramentas e Tecnologias
Python 3.x

Pandas

Matplotlib / Seaborn / Plotly

Jupyter Notebook


🔍 Etapas da Análise
Coleta e limpeza de dados

Exploração estatística (média, mediana, desvio padrão)

Visualizações geográficas e temporais

Comparação entre estados e regiões

Conclusões e interpretações econômicas
